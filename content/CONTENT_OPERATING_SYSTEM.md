# Content Operating System

Purpose: manage posts, schedule, writing, images, videos, review, and post-publish
learning.

## Weekly Rhythm

Monday:

- Review market environment.
- Pick weekly theme.
- Draft 3 short posts and 1 deeper post.

Tuesday to Thursday:

- Publish short posts.
- Reply to comments.
- Capture audience questions.

Friday:

- Publish deeper analysis or demo post.
- Review metrics.
- Decide next experiment.

Weekend:

- Batch research, visuals, and MVP improvements.

## Content Pipeline

```text
Idea -> Brief -> Draft -> Visual/Asset -> Review -> Schedule -> Publish -> Metrics -> Learning
```

## Review Checklist

- Is the hook specific?
- Is the reader's pain clear?
- Is the analysis sourced or framed as opinion?
- Are uncertainty and invalidation stated?
- Is the CTA simple?
- Is the format native to the platform?
- Does the post avoid overpromising?
- Is any position or conflict disclosed?

## Asset Types

- Chart screenshot.
- Annotated chart.
- Workflow screenshot.
- Demo GIF/video.
- Carousel/checklist.
- Thumbnail.
- Short video script.
- Blog header image.

## File Convention

```text
content/
  drafts/
  published/
  scripts/
  visuals/
  metrics/
```

Use date-first names:

```text
2026-05-07_market-regime-thread.md
2026-05-07_ai-agent-demo-script.md
```

## Post-Publish Review

For each meaningful post, record:

- What was the hypothesis?
- What happened?
- Which metric mattered?
- What replies or DMs appeared?
- What should be repeated?
- What should be stopped?
- Did it create an MVP or product clue?
