  1. Step 1（先學 domain）：AI Server 元件 Primer — 散熱、BOM、GB300 整櫃、HBM、被動元件、ASIC BOM 是什麼。如果你還不能用自己的話講出這些，先回去讀 primer。
  2. Step 2（再讀 source）：Cooling BOM Cross-Source Reading — Card #001 引用的 4 份 source 各能支持什麼、不能支持什麼。讀完後你才知道哪些數字可信。
  3. Step 3（最後審稿）：本頁 — 審公開貼文 + 回兩個 reviewer 問題。

讀完 Step 1 + 2 後，你應該記住的事

  • GB300 一櫃不是「GPU 一張」，是整套 rack-level system，售價約 $600K。
  • BOM 是零件成本表，不是 revenue。
  • 「散熱占整櫃 42%」算術不通，不要寫。
  • 「GB300 一櫃液冷 BOM 接近 $50K」是兩個獨立 secondary 一致的，可用，但要標 secondary。
  • 「132-140kW rack power、1400W per GPU」跟 NVIDIA 公開 spec 一致，最硬。
  • 奇鋐 30%、Vertiv 35% 之類市占數字 避開百分比，改寫角色定位。
  • Component supplier（奇鋐做零件）跟 system integrator（Vertiv 整合 rack）不能直接比百分比。

如果以上有任何一條你看不懂，請回 Step 1 primer。Step 1 的成功標準就是你能用自己的話說出這些。

1. 貼文草稿（你要審的就是這段）

平台：X long post 為主，1 小時後 Threads carousel。連結 CTA 連回 library。字數 ~600。

— 這個方塊裡就是準備發到 X / Threads 的內容 —

GB300 一櫃要花接近 $50K 在液冷上。

這是我最近整理 AI server 供應鏈時，覺得最有記憶點的一個數字。

先翻成人話。

GB300 NVL72 不是一張 GPU，而是 NVIDIA 新一代 AI server rack。一櫃裡面有 72 顆 B300 GPU，滿載功耗大概 132-140kW。

140kW 是什麼概念？

你可以先不用管工程細節，只要知道：這一櫃本質上就是一個很貴、很密集的熱源。

熱排不出去，GPU 會 thermal throttle，也就是自己降速保命。你買了很貴的算力，但跑不滿，就是在浪費錢。大企業當然不會讓這種事發生。

所以液冷開始從 optional 變 required。
這就是為什麼散熱開始從「風扇」變成「一整套水路」。

拆開看，大概有幾段：

  • cold plate：貼在晶片上，把熱帶到冷卻液
  • CDU：整櫃冷卻液循環的主機
  • manifold：把冷卻液分到不同 tray
  • UQD：讓 tray 維修時不漏液

公開拆解資料給的量級是：GB300 NVL72 單櫃液冷 BOM 約 $49,860，GB200 約 $41,500。

BOM 就是零件成本表。這個數字不是某家公司直接賺到的營收，但它告訴我：每一櫃 AI server 裡，散熱這個 category 的 content 變大了。

對應到公司，先粗分：

  • 奇鋐 / AVC：cold plate、液冷模組
  • 雙鴻 / Auras：manifold、液冷 solution
  • Vertiv：rack / data center 層級 cooling infrastructure

所以這條線我會這樣看：

AI 算力需求上升
→ GPU power density 上升
→ rack cooling 從 optional 變 required
→ cooling BOM per rack 上升
→ 對應零件供應商的 ASP / volume 有機會上升
→ 最後回到法說驗證 revenue、margin、backlog

我目前比較想追三個訊號：

  1. NVIDIA 下一代 rack power envelope 有沒有繼續往上
  2. 奇鋐 / 雙鴻法說有沒有講 AI rack / NVDA 平台 exposure
  3. Vertiv 的 cooling infrastructure backlog 有沒有真的放大

這條線我會先放一個反向檢查點（算一種利多出盡吧）：如果未來兩年 AI rack 還是以過渡型液冷為主，沒有更快走向 direct-to-chip / 全液冷，那 cold plate、manifold、CDU 這些零件的成長速度可能就沒有想像中快。

但至少目前看到的產業資料，方向是 OK 的。

所以統整完上面這些資料，我目前得到的結論是：

散熱開始被市場重新看見，我現在理解比較像是：AI server 變成一櫃一櫃的系統在賣，所以它上面的散熱組件也會被一起綁進去。只要 rack-level system 出貨，cold plate、CDU、manifold 這些東西就會跟著有連帶關係。

如果未來一切都很美好，AI rack 繼續往更高功耗走，這條線會繼續值得追。反過來，如果液冷 adoption 卡在過渡方案，或供應商法說沒有轉成 backlog / margin，那就要小心一點。(+馬)

但我目前覺得本質沒有變。只要算力還在短缺，rack power 還在往上，液冷應該就是 AI server 基本面裡一個很好的支撐點。

4. 你只要回兩個問題

問題 A · 持倉揭露

User answer: D（修正） 可以直接講具名公司，但用泛用揭露處理利益衝突。因此公開稿保留奇鋐 / 雙鴻 / Vertiv，並加一句「作者可能持有文中提及個股」。

你目前是否持有以下任一張？或近 30 天內有交易？

  • 奇鋐（3017.TW）
  • 雙鴻（3324.TW）
  • Vertiv（VRT）

四個選項挑一個：

  • (a) 三家都沒有持倉 / 30 天內無交易 → 加一行：「持倉揭露：作者目前未持有 奇鋐、雙鴻、Vertiv，且 30 天內無交易。」
  • (b) 有 1 張持倉 → 告訴我哪一張、方向（多 / 空）、大致時點
  • (c) 有 2 張以上 → 列出來
  • (d) 不揭露具體位置但有持倉 → 加「作者可能持有 X，揭露細節保留」並考慮要不要延後 ship 給自己時間清倉或重新框架

目前採用「具名公司 + 泛用持倉揭露」路線。如果之後要改成精確持倉揭露，可以再更新。

問題 B · BOM 分母怎麼寫

User answer: A 維持保守版，只寫 ~$49,860 / rack，不講百分比。

三個選項挑一個：

  • (a) 保守版（目前 draft，建議）：只寫 ~$49,860 / 櫃，不講百分比；Caveat 已揭露分母衝突。最快可 ship
  • (b) 透明版：Caveat 段加「公開拆解對分母不一致，所以我用較保守口徑」；額外耗時 10 分鐘。教育性最高
  • (c) 延後 3-7 天：等 Morgan Stanley 原文 / Vertiv investor day / NVIDIA OCP 公開拆解。可能等不到

讀完 source tutor 後，我（agent）建議是 (a)。理由：這份 set 不會升到 primary，延後也不會有更硬的數字。
