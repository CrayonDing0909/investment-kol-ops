## Main post

```text
【AI Server 系列・EP1】

最近在整理 AI server，我發現自己一開始看太粗了。

我原本以為，AI server 大概就是「很多張很猛的 GPU 插在一起」。

結果越看越覺得，不是這麼簡單。

它比較像一台很貴、很熱、又很難組起來的機器。

這集先不講公司，也不講買賣。
我只想先把這個想法講清楚。👇
```

## 1/ — 我以前為什麼會搞錯

```text
我以前為什麼會搞錯？

因為大部分新聞都會讓你把注意力放在「那張最猛的運算卡」上。

這很合理。
畢竟那是最貴、最顯眼、也最容易被討論的東西。

（我一開始也是這樣想：不就是很多張卡插在一起嗎？）

但後來才發現，那只是整台機器的一部分。

1/
```

## 2/ — 為什麼「貴」

```text
先講「貴」。

它貴，不只是某一個零件很貴。

而是整套東西都要一起到位：

算得要快，
資料要跟得上，
熱要帶得走，
電要撐得住，
最後還要有人把整套東西組成真的能出貨的機器。

少一塊，都不是完整的 AI server。

2/
```

## 3/ — 為什麼「熱」

```text
再來是「熱」。

這個是我以前最容易忽略的地方。

我原本以為，AI server 的重點就是「算得夠不夠快」。

後來才發現，另一個很現實的問題是：
它熱到你不能只把它當成一般電腦看。

一般電腦熱了，你想到的是多裝幾個風扇。
但這種等級的機器，如果熱帶不走，它會自己降速保命。

這也是我覺得最反直覺的地方：

你以為你在買更快的運算，
但其實你也在買一整套「讓它不要熱到跑不滿」的系統。

3/
```

## 4/ — 為什麼「難組」

```text
最後是「難組」。

它不是把零件買來、塞進去、接上電就好。

每一塊都會互相限制：

算得快，但資料餵不進去，不行。
資料餵得進去，但熱帶不走，也不行。
熱帶得走，但整機組不起來，還是不行。

所以它比較像一整套系統，不是一堆零件清單。

4/
```

## 5/ — 為什麼我重新整理

```text
這也是我這次重新整理 AI server 的原因。

我以前會太快問：

「有哪些公司在裡面？」

但現在我覺得應該先問：

「這台機器到底怎麼成立？」

先看懂機器，再看零件。
不然很容易變成背名詞。

5/
```
