2. 最刺眼的衝突：「占整櫃 42%」根本算不通

不要寫「散熱占 GB300 整櫃成本 42%」

$49,860 / $600,000 = 8.31%，這跟「占 42%」差超過 5 倍。內部就算術不通。

這不是我們自己算出來的。這句話來自二手 source：EE Times China / 產業拆解文章在講 GB300 散熱系統時出現了「約 $49,860 / 櫃，約占整櫃價值 42%」這類說法；LianLi Work 也提到接近 $50K / 櫃，並說引用 Morgan Stanley / supply-chain data。

問題是：如果同時採用 cooling BOM = $49,860 和 total rack = $600,000，計算結果是 8.31%，不是 42%。所以這不是「我們整理錯一點點」，而是 source 內部可能混用了不同母體。

可能原因有四種：(a) EE Times / LianLi 抄錯或混用不同口徑；(b) $600K 不是用來算 42% 的分母；(c) $49,860 只是一部分 cooling BOM，$380K 是另一個更大口徑 cooling system；(d) Morgan Stanley 原文裡有不同機櫃配置，但二手文章混在一起。

不管哪一種，結論一樣：發貼文不要引用 42% 這個百分比，因為任何人按計算機都會發現算不通。

這個衝突在教我們什麼？

  • Industry teardown 要逐條校對：拿到任何 BOM 拆解，自己先按一遍百分比。
  • 分析師會把不同口徑的數字放在同一段：「$49,860 cooling BOM」與「occupies 42% of $600K rack」可能來自兩個不同口徑的拆解，但被同一篇文章拼在一起。讀者沒注意就會以為是一回事。
  • safer wording 是給絕對金額，不給百分比：Card #001 改成「GB300 一櫃液冷 BOM 接近 $50K」，避開比例。

3. 讀 Industry Teardown 的 4 個原則

這是「跨二手源整合」的閱讀方法。可以直接套到 HBM、被動元件、ASIC BOM 等任何「industry analyst 拼出來的數字」上。

  1. 獨立 evidence chain 才算多源。
    LianLi 引 Morgan Stanley、Vocus 自己整理，但這兩家可能都在引用同一份 Morgan Stanley note。真正獨立的 secondary 大概只有 2 條，不是 4 條。
  2. Source class 階層不變。
    primary > high-quality-secondary > secondary > tertiary。這份 set 沒有 primary，所以結論天花板是 secondary。
  3. 分析師重複的 framing 不能跨源累加。
    「散熱占 42%」這句話被多家轉述，不代表它變成事實。如果原始就是一份 Morgan Stanley note 算錯，後面所有人轉述都會錯。
  4. Forward-looking 不能因為被多家轉述就升等。
    TrendForce 的「GB300 占 70-80%」是 2026 全年 forecast。即使 LianLi 也轉述，仍是 forward-looking，不是 reported-fact。

4. 每條 thesis 多硬？

這裡的「多硬」不是股價強弱，也不是投資機會大小，而是：這句話有多可信，能不能拿去公開寫？

怎麼看 strong / medium / weak / open conflict

強度意思通常長怎樣公開寫法
strong 可以比較安心公開寫 有 primary source / reported fact / 多 source 一致 / 沒有內部矛盾 可直接寫，但仍保留時間與來源
medium 可以寫，但要加來源標籤或 caveat 二手 source、industry estimate、forecast、多 source 但可能同源 寫「公開拆解 / TrendForce 預期 / secondary」
weak 不建議寫成精確事實 單一二手來源、市占百分比、口徑不清楚、沒有公司 IR / 法說支撐 避開百分比，改寫角色定位或方向
open conflict 不能寫，不是「弱」而是目前矛盾 同組數字彼此算不通，或來源自相矛盾 不寫；若必要，寫成「口徑衝突」

5. 哪些數字不能直接拿去公開寫

#原本想寫的數字為什麼有風險safer wording
1 「散熱占 GB300 整櫃 42%」 $49,860 / $600,000 = 8.31%，算術不通 不用百分比；改用「~$50K / 櫃」絕對金額
2 「整櫃成本 $600K」 LianLi 同篇文章又出現 $380K，母體不一致 不引整櫃成本，只引「cooling BOM 約 $49,860」
3 「奇鋐 cold plate 30%+ 市占」 口徑（NVDA-only / 全平台 / 含 ASIC）未驗證 「奇鋐 / AVC 是 cold plate 主要供應商之一」
4 「Vertiv 拿液冷 ecosystem 35%+」 EE Times 單一 secondary 估計，無第二源獨立驗證 「Vertiv 是 rack / data center 層級 cooling infrastructure 主力之一」
5 「GB300 占 2026 rack shipments 70-80%」 TrendForce forecast；2026 還沒過完 「TrendForce 預期 GB300 將是 2026 主流」，不寫具體百分比
6 「液冷滲透率突破 50%」 TrendForce forecast；2026 主要還是 liquid-to-air 過渡 「液冷滲透率往 50% 走，但 2026 仍以 liquid-to-air 過渡為主」

6. 這份 set 能證明什麼 / 不能證明什麼

能直接公開引用的

  • AI server 機櫃從風冷切到液冷後，散熱從風扇 + heat sink 變成 cold plate + CDU + manifold + UQD 一整套 plumbing（公開事實）。
  • GB300 一櫃液冷 BOM 在 $40K-$50K 量級（兩個獨立 secondary 一致，方向感對）。
  • GB300 滿配 rack 功耗 132-140kW、B300 GPU 1400W（NVIDIA 公開 spec 一致）。
  • 奇鋐 / 雙鴻 / Vertiv 是液冷供應鏈裡有明確角色定位的玩家（角色 OK，百分比 not OK）。

這份 set 不能證明的

  • 散熱占整櫃 42% — 算術衝突，不是事實。
  • 奇鋐冷板市占的精確口徑（NVDA-only？全平台？含 ASIC？）。
  • Vertiv 35%+ 是真的、還是分析師估計。
  • GB300 mass-deployment 真正 ramp 月份。
  • 純液冷 vs 過渡液冷 2026 真正比重。

7. Mental Model 升級

  • AI server 散熱 = 物理瓶頸 + 系統級 BOM。
    Rack 功耗從 ~50kW 跳到 132-140kW，風冷物理上不夠，散熱從旁料變必要系統零件。這條被 NVIDIA primary spec 支持，可長期套用到任何 AI server 公司分析。
  • Industry teardown 要逐條校對，不能整套引用。
    Source 1 自己內部就有 $49,860 / $600K 與 42% 算術衝突。教訓：拿到任何 BOM 拆解，先自己按計算機。
  • 「多源一致」要看是不是獨立 evidence chain。
    4 份散熱 source 表面互相支持，但 LianLi 跟 Vocus 可能引同一份 Morgan Stanley note。真正獨立的 secondary 大概只有 2 條。
  • 供應鏈受惠要拆零件，不能講「散熱概念股」。
    cold plate / CDU / manifold / UQD 四段各自市占不同；奇鋐、雙鴻、Vertiv、建準位置不同。公開寫作必須對應到具體角色。

  • (a) 保守版（目前 draft）：只寫「GB300 一櫃液冷 BOM 接近 $50K」，不講百分比。最安全
