AI Server Supply Chain

AI server 的資金支出結構正在從 GPU 主導，外溢到 CPU、ASIC、memory、passive components、cooling、software。 這頁是這條供應鏈的入口；每個 topic 卡片連到細節頁。第一個 anchor deep dive 是 CPU 復興（M1）。
Last updated: 2026-05-10 · Anchor deep dive: CPU 復興 · Status: draft

核心 thesis

EP659 之後可以記下這條主敘事：當市場接受 AI 算力的 spend 不會單押 GPU，資金會擴散到三個方向 —— （1）回到 CPU 與 ASIC 等 compute 旁支；（2）灌進 server OEM 與被動元件、散熱等基礎建設； （3）回流到財務體質好的軟體股。每條都需要不同的 catalyst 才會啟動。

  • GPU 不是「死了」，是「不再是唯一買點」。
  • CPU 透過 AMD / Intel 法說回到敘事中心，AI server 對 CPU 的需求在 reaccelerate。
  • ASIC 受 hyperscaler（AWS / Google）自研晶片需求帶動，估值仍相對便宜。
  • 被動元件（信昌電 / MLCC / 鉭電容）供需吃緊，但敘事尚未啟動，要等 catalyst。
  • 散熱在 EP659 缺席，但是 AI server 的必經環節，需另尋 intake。
  • 軟體裡 PLTR / NET / CRWD 被點名為「二軍」候補，前提是一軍轉弱。
