ASIC 浪潮

Hyperscaler 自研 AI 加速器（AWS Trainium、Google TPU 等）正在把資金從通用 GPU 牽到客製 ASIC；MediaTek Q1 2026 secondary sources 指向 Q4 2026 約 $2B AI ASIC revenue 目標，Intel 也揭露 ASIC revenue QoQ +30% / YoY nearly doubled。台廠創意 / 世芯仍是設計服務節點，客戶集中度高。
Last updated: 2026-05-10 · Status: draft · Theme: asic

1. 這是什麼？

ASIC（Application-Specific Integrated Circuit）是針對單一工作負載最佳化的客製晶片。對 hyperscaler 而言，自研 ASIC 可以省成本、擺脫 NVDA 議價權。 在 AI server 場景，ASIC 主要做 training / inference，跟通用 GPU 形成替代或互補關係。

  • 客製化 → 同樣工作負載下 perf-per-dollar / perf-per-watt 比 GPU 好。
  • 缺點：開發週期長、客戶綁死、規模不夠就不划算。
  • Hyperscaler 是天然客戶：採購量大、工作負載穩定、有自家工程團隊。

3. 為什麼現在重要？

  • EP659：「現在除了 GPU 沒力氣以外，一堆資金灌進 ASIC。」
  • 世芯漲停且高度綁定 AWS Trainium，反映市場對 ASIC theme 的認知度提升。
  • 創意也跟著 Google TPU 故事起飛了一段。
  • 大市值 ASIC 估值約 30 倍，相較於光通股交易兩三年後到 100 倍，風險回報比看起來便宜。

4. 現在的產業趨勢

已知事實

  • 世芯與 AWS Trainium 高度綁定（公開供應關係）。
  • 創意過去因 Google 案上漲一段。

市場敘事

  • 「資金從 GPU 轉到 ASIC」。
  • 「30 倍 ASIC 比 100 倍光通便宜」。

還沒驗證的假設

  • EP659 講的「30 倍 ASIC」具體是誰（AVGO？MRVL？或台廠？）。
  • hyperscaler 採購 ASIC 的真實 ramp 速度。

可能被否證的訊號

  • MediaTek 官方 transcript 若無法支持 $2B Q4 ASIC revenue 或 TAM/share target。
  • AVGO / MRVL 法說 ASIC segment 弱於 guidance。
  • 世芯 / 創意大客戶 design loss。
  • NVDA 推出針對 ASIC 客戶的折扣或 reference design 把 hyperscaler 拉回 GPU。

5. 哪些公司受影響？

Ticker / Name角色Bull caseBear case
AVGO大市值 ASIC + 網通Hyperscaler 客戶基礎廣，ASIC + 網通雙引擎。Custom silicon 採購節奏未如預期。
MRVL大市值 ASIC + 光通同時受惠 ASIC 與光模組需求。客戶過度集中，個別客戶調整影響大。

3661.TW（世芯-KY）設計服務AWS Trainium 案規模放大。客戶綁死、議價力弱。

6. 市場現在 pricing 什麼？

Pricing 在「ASIC = 下一個 GPU」這條 narrative。AVGO / MRVL 的本益比約 30x，反映成長 + multi-product 結構； 台廠創意 / 世芯估值反映「拿到大案 + 客戶綁定」的故事，但毛利結構偏設計服務、不像 NVDA 是 product margin。

不確定處：30x ASIC 是 forward 還是 trailing P/E、是否已 priced-in 多個未公布的 design wins，需要更精細的對照。
