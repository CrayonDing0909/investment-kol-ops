CPU 復興

AI server 的 spend 結構讓 CPU 從「commodity 旁角」重新回到中心舞台；AMD 以 EPYC 抓住 server CPU TAM 上修，Intel 則把 Xeon 重新定位成 AI stack 的 orchestration / control plane。聯發科仍偏 I/O / memory subsystem 與 ASIC exposure，尚未證明自己進入 server CPU 主晶片。
Last updated: 2026-05-10 · Status: draft · Theme: cpu

1. 這是什麼？

CPU（Central Processing Unit，中央處理器）是伺服器的「總指揮」：負責調度任務、跑作業系統、處理 I/O 與通用運算。在 AI server 裡，CPU 雖然不負責矩陣計算（那是 GPU/ASIC 的事），但仍是把資料搬給 GPU、處理控制流、跑前處理 / 後處理的關鍵零件。

  • 每台 AI server 仍會配 1-2 顆 CPU，與 4-8 顆 GPU/ASIC 搭配。
  • 主要供應商：x86 雙雄 AMD（EPYC）與 Intel（Xeon）；ARM 派系包含 NVDA Grace、AWS Graviton。
  • 台廠目前以「I/O 與 memory subsystem」周邊切入（聯發科），尚未真正做主晶片。

2. 用在哪裡？在供應鏈的位置

CPU 在 AI server 內負責協調，是 GPU / ASIC 之外的另一條 spend 主軸。

環節角色代表公司
x86 server CPU主晶片AMD（EPYC）、Intel（Xeon）
ARM server CPU主晶片NVDA Grace、AWS Graviton、Ampere
I/O / memory subsystem周邊 + interconnect聯發科、Astera Labs、Marvell（部分）
封裝 / 代工foundryTSMC（2330.TW）

3. 為什麼現在重要？

  • AMD source-backed 修正：120B 指的是 server CPU TAM by 2030，不是 AMD 2026 revenue。AMD Q1 2026 Data Center revenue $5.8B、+57% YoY，並說 server CPU TAM CAGR >35%。
  • Intel source-backed：Intel 說 CPU 是 AI stack 的 orchestration layer / control plane；Q1 2026 DCAI revenue $5.1B、+22% YoY，Xeon 6 被選為 NVIDIA DGX Rubin NVL8 host CPU。
  • 美股大跌時 CPU 族群相對強勢，這是技術面已先反映的訊號。
  • 聯發科第一次出現多根漲停，市場對台廠切 server CPU 周邊的想像升溫。

4. 現在的產業趨勢

敘事中心明確、但個股估值已開始打滿，要分清楚事實與敘事。

已知事實

  • AMD 官方 source 支持：Data Center revenue $5.8B、+57% YoY；server CPU TAM >$120B by 2030、CAGR >35%。「市占 >50%」仍需 Analyst Day primary source。
  • 聯發科股價於 EP659 錄製當週反應到 ~3000 TWD 級。

市場敘事

  • 「CPU 重新成為市場核心」。
  • AI server 的下一個 spend 環節從 GPU 走向 CPU。

還沒驗證的假設

  • 聯發科從 I/O / memory subsystem 走到「打入主晶片」的路徑與時間。
  • AMD >50% 伺服器市占目標仍待 primary source；目前 source-backed 是 server CPU revenue growth / TAM 上修。

可能被否證的訊號

  • AMD / Intel 下一份法說的 server segment 數字弱於 guidance。
  • 聯發科進入主晶片的進度被時間表延後或被客戶否認。
  • hyperscaler capex 重新偏向 GPU/ASIC，CPU 配比下調。

6. 市場現在 pricing 什麼？

AMD 已 pricing「Data Center revenue inflection + server CPU TAM 上修 + EPYC 需求強」；聯發科股價則反映 AI ASIC / data center subsystem story，但仍要分清楚 ASIC revenue、I/O subsystem、server CPU 主晶片是三件不同事。 Intel 的 source-backed story 是 DCAI 復甦、Xeon 作為 AI control plane、Foundry/packaging leverage，但也有 18A ramp 和 cost pressure。

不確定處：AMD 的 50% 市占目標是否已被估值反映，需要再看 forward P/E 與 hyperscaler 採購節奏。

7. 我還不懂的部分

Q: 為什麼 AI server 工作負載不是只吃 GPU？
A (草稿)：CPU 仍負責 host code、資料 pre/post processing、I/O 排程、跨 GPU 同步。GPU 數量越多，CPU 的協調工作越關鍵；模型規模越大，CPU 與 memory subsystem 之間的資料搬運成為新瓶頸。
Q: 聯發科切的 I/O / memory subsystem 是什麼？跟主晶片的距離有多遠？
A: open（需要找聯發科法說 / 報告補完。可能對應 PCIe switch、CXL controller、或 memory expander。）
