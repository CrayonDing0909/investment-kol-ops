1. 這是什麼？

散熱方案把 GPU / CPU / ASIC 產生的熱搬離晶片，主要分成風冷與液冷兩大路線。AI server 因為 GPU TDP 從 ~700W 走向 1000W+，rack 級功率破百 kW，傳統風冷已逼近極限，液冷（直接接觸晶片或浸沒式）成為主流。

  • 3D VC（Vapor Chamber）：高效熱導板，提升風冷上限。
  • Cold Plate / Direct-to-Chip Liquid Cooling：水冷板直接貼晶片。
  • CDU（Cooling Distribution Unit）：rack 內冷卻液分配與熱交換。
  • Quick Disconnect：水冷管快接頭。
  • 浸沒式（immersion）：整台 server 浸在介電液裡。
