散熱系列

從一台 Tesla 開始，搞懂 AI server 為什麼要花 $50K 在液冷上
3 集 · 1/3 已發 explainer → mechanism → thesis 預計每週一集
這個系列拆三步：先用一個工程師都看得懂的對比講「為什麼 AI server 突然變成散熱題」（第一集，無個股）；接著拆「一櫃液冷 $50K 怎麼分」（第二集，零件與成本結構）；最後才談「這筆錢流到哪幾家、為什麼我還不急著喊散熱概念股」（第三集，含持股聲明）。

順序很重要：直接從第三集開始看不會被擋，但跳過第一集你會少掉一個很有用的記憶點。

EP 01 · explainer 已發布
為什麼一台 AI server 一個月電費比一台 Model S 還貴
Tesla Model S 一年充電 ~4,000 度。一台 GB300 機櫃一個月吃 ~95,000 度。一櫃 AI server 跑一個月，等於一台 Tesla 開了 24 年的電。這就是為什麼散熱突然變成關鍵字。沒有個股、沒有投資判斷。

一櫃 GB300 為什麼要花 $50K 在液冷上

為什麼這樣排

這個系列的結構是學自 Threads 帳號 @10m.engineer.investor 的 9 集量子計算系列：第一個月做 ~70% 的 follower 成長，靠的是「先科普 8 集 + 投資反向觀點 1 集」。

所以這裡也是先 explainer 建立背景知識和信任，再進 mechanism 解構零件，最後才是 thesis（含持股 disclosure）。完整方法論寫在 這份 deep-dive 研究（md source） 裡。
