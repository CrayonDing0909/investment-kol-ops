1. 先建立 Mental Model — AI Server 6 層架構

AI server 不是「一張 GPU」。它是一整套工業設備，真的就是一層一層堆起來：晶片先放到封裝上，封裝後焊到主板，主板裝進可抽換的 tray，多個 tray 裝成一櫃 rack，很多 rack 放進 data center。

Chip 晶片 → Package 封裝 → Board / PCB 主板 → Compute Tray 運算托盤 → Rack 機櫃 → Data Center 資料中心

你可以先用這個比喻記：

CPU / GPU引擎，真正做運算。
Package 封裝引擎底座，把 GPU、HBM 放得很近。
PCB 主板車架和電線，把電與訊號送到各處。
Tray 運算托盤可抽換的引擎模組，壞了可以維修。
Rack 機櫃一整台賽車，裡面有很多 tray。
Data Center整個賽車場，供電、散熱、網路都在這層。

下面這張圖從底層往上看，越上面越貴、越下游、越接近 capex；越下面越小、越上游、越接近物理。

6L6
Data Center 資料中心
很多 rack 放在一起的「賽車場」：供電、散熱、網路都在這層。AI 單站功耗從 30MW 走向 1GW+。
Hyperscaler 自建 Equinix
5L5
Rack 機櫃
一整台「賽車」：GB300 NVL72 是 72 GPU + Grace CPU + 散熱 + 電源的 rack-level system。132-140kW、~$600K/櫃。
NVIDIA Vertiv (CDU) Foxconn Quanta
4L4
Compute Tray 運算托盤
可抽換的「引擎模組」。裡面有 GPU、Grace CPU、HBM、冷板、電源、連接器、快接頭。UQD 讓 tray 維修時不漏液。
奇鋐 (cold plate) 雙鴻 (manifold) OEM/ODM
3L3
Board / PCB 主板
車架和電線：封裝後的晶片焊到 PCB，主板靠 traces / connector 接訊號與電。MLCC 像小型穩壓水庫，AI 主板高階用量 5-10x。
Yageo 國巨 村田 太陽誘電
2L2
Package 封裝
引擎底座：GPU 要跟 HBM 很近地放在一起，靠 CoWoS 接起來。CoWoS 產能不夠，就算有 GPU + HBM 也組不出完整 AI chip。
TSMC (CoWoS) ABF 載板 (味之素) 日月光
1L1
Chip 晶片
真正做運算的引擎：GPU / CPU / ASIC / HBM。TDP = 滿載時散熱系統要排掉多少熱；700W → 1400W 代表單顆 GPU 熱量變 2 倍。
NVIDIA AMD Intel Broadcom SK hynix (HBM)
關鍵心法：AI server 投資不是「GPU 受惠」這一條，是 6 層 × 各自玩家 × 各自瓶頸 的網狀故事。任何只看一層的分析都太粗。

2. 產業上中下游（板塊圖）

另一個切法是「錢和物料怎麼流」。上中下游不是「所有原料清單」，而是看一筆 hyperscaler capex 怎麼一路變成各家供應商的收入。

上游 (製造能力 / 關鍵材料 / 關鍵產能)  →  中游 (晶片設計 / 模組 / 系統零件)  →  下游 (整機組裝 / hyperscaler 採購 / 算力使用)

上游 Upstream

不是「所有原料」，而是 AI server 能不能做出來的關鍵供應瓶頸。
晶圓 + 封裝
  • TSMC（GPU / ASIC / HBM 都要走這）
  • TSMC CoWoS（先進封裝瓶頸）
  • 日月光、Amkor（傳統封裝）
記憶體
  • SK hynix（HBM 龍頭）
  • Samsung（HBM 追趕）
  • Micron（HBM 受美國政策加分）
載板與被動料
  • 味之素 ABF substrate
  • 欣興、南電 ABF 載板代工
  • Yageo、村田、太陽誘電（高階 MLCC）

中游 Midstream

把上游能力轉成可出貨的晶片、模組、系統零件。
GPU / CPU 設計
  • NVIDIA（GPU + Grace CPU + rack reference design）
  • AMD（EPYC CPU + Instinct GPU）
  • Intel（Xeon CPU + Gaudi）
ASIC 設計合作
  • Broadcom（Google TPU、Meta MTIA）
  • Marvell（AWS Trainium 2）
  • Alchip、GUC（亞洲 ASIC 設計服務）
散熱模組
  • 奇鋐 AVC（cold plate）
  • 雙鴻 Auras（manifold / liquid module）
  • Vertiv（rack-level CDU / 整合）
  • 建準 Sunon（hybrid air/liquid）

下游 Downstream

把 rack 組出來、賣給 hyperscaler，最後變成可用算力。
ODM 整機組裝
  • Foxconn 鴻海
  • Quanta 廣達
  • Wistron 緯創
  • Supermicro
Hyperscaler（真正的買方）
  • Microsoft Azure
  • Meta
  • Google Cloud
  • Amazon AWS
  • Oracle / CoreWeave（neo-cloud）
最終買單
  • AI 模型公司（OpenAI、Anthropic 等）
  • 企業 SaaS 整合
  • 政府 / 主權 AI 採購
讀法：同一家公司可能跨多層（NVIDIA 同時做 chip + reference rack design），但分析「誰受惠」時，要先放到正確的位置。例如奇鋐是中游零件廠，Vertiv 是中游系統整合，Foxconn 是下游 ODM，不能直接比百分比。

錢怎麼流？從 hyperscaler capex 到供應商收入

1. Hyperscaler capex：Microsoft / Meta / Google / Amazon 決定多買 AI 算力。
2. NVIDIA rack order：買的不只是 GPU，是 GB300 / NVL72 這種整櫃 reference design。
3. ODM 組裝：Foxconn / Quanta / Wistron / Supermicro 把整櫃組出來。
4. NVIDIA reference design 指定零件：rack 裡需要 HBM、CoWoS、ABF、MLCC、cold plate、CDU、manifold、UQD。
5. 上游 / 中游供應商出貨：SK hynix 出 HBM，TSMC 出 CoWoS，奇鋐 / 雙鴻 / Vertiv 出液冷相關零件，國巨 / 村田出高階被動元件。
6. 最後看財報驗證：真的有沒有反映到 revenue、gross margin、backlog、客戶暴露比例。

所以一篇投資內容不應該停在「誰在供應鏈」。它要回答：這家公司卡在哪個必要環節？那個環節的 BOM / ASP / volume 有沒有變大？財報能不能驗證？

3. 6 個關鍵元件（卡片速覽）

下面 6 張卡片是 Card #001 / 未來 cards 會反覆引用的關鍵詞。每張卡：一句定義 + 一個關鍵數字 + 一個易錯點。詳細解釋見 §4。

散熱 Cooling L4-L6
把晶片產生的熱搬走。AI rack 功耗破 130kW，風冷帶不走，必須切液冷。
關鍵數 GB300 一櫃液冷 BOM ~$50K
易錯：「散熱概念股」太粗。拆 cold plate / CDU / manifold / UQD 四段。
BOM 物料清單 跨層概念
一台設備的零件成本表。每個零件多少錢、占整台百分比。不是公司營收。
關鍵數 GB200→GB300 cooling BOM $41.5K → $49.86K（+20%）
易錯：把 BOM 數字當 revenue。BOM = 零件成本，revenue = 公司營收。
GB300 整櫃 NVL72 L5
NVIDIA 賣的不是「一張 GPU」，是整套 rack-level system（72 GPU + 36 Grace + 散熱 + 電源）。
關鍵數 一櫃 ~$600K、132-140kW、~1500kg
易錯：把 GPU 單片價格跟整櫃價格混為一談。
HBM 高頻寬記憶體 L1-L2
3D 堆疊放在 GPU 旁邊的記憶體，解決 memory wall。HBM ≠ 一般 DRAM。
關鍵數 比 DDR 貴 5-10x；SK / Samsung / Micron 三家
易錯：「HBM 漲價 = DRAM 漲價」。HBM 是高階 niche，跟 commodity DRAM 兩條曲線。
被動元件 L3
電容 / 電阻 / 電感。不是 IC，但高功耗 AI 主板需要 5-10x 高階料來穩定供電。
關鍵數 AI 主板高階 MLCC 用量 5-10x 一般 server
易錯：「被動元件 = 低附加價值」。高階 MLCC ASP 拉動明顯，毛利不低。
ASIC BOM L1（平行）
Hyperscaler 自研晶片（TPU、Trainium、MTIA、Maia）。整套 BOM 跟 GPU 是平行供應鏈。
關鍵數 設計合作：Broadcom (Google/Meta)、Marvell (AWS)
易錯：把 ASIC 寫成「GPU 外溢」。兩條 BOM 各自獨立，不是延伸。

4. 每個元件深入解釋

下面 6 個 details 是上面卡片的深入版本。預設折疊，按需要打開。

散熱（Cooling）— L4 至 L6

是什麼：把晶片產生的熱搬走，讓晶片不會 thermal throttle 或燒掉。

在哪層：橫跨 L1（晶片表面）、L4（tray 內管路）、L5（rack 級 CDU）、L6（data center 冷卻塔）。

thermal throttle 是什麼：晶片太熱時，為了不燒掉會自動降頻。你花大錢買 GPU，但熱排不出去，它就自己降速保命，算力跑不滿。所以散熱不是「讓機器涼一點」而已，而是保證昂貴 GPU 可以長時間滿載運轉。

為什麼變大事：

  • H100 700W → B200 1000W → B300 1400W per GPU
  • GB300 NVL72 滿配整櫃約 132-140kW
  • 空氣冷卻單顆極限 ~700W；超過就帶不走熱
  • 液冷的傳熱效率比空氣高 1000 倍以上

散熱拆 4 段（投資 lens 從這裡開始）

段是什麼角色玩家
Cold Plate水冷板，直接貼晶片晶片 → 冷卻液的第一站奇鋐 / 雙鴻 / Cooler Master
CDUCoolant Distribution Unit，rack 級分配整櫃的「心臟」Vertiv / Schneider
Manifold管路歧管rack 內部分流雙鴻
UQD快接頭，tray 維修不漏液tray 維修介面安費諾

它到底怎麼散熱？

GPU 發熱 → 熱傳到 cold plate → 冷卻液帶走熱 → manifold 分流到不同 tray → CDU 控制整櫃循環 → 熱進 data center 冷卻系統

可以想成水冷電腦，但 scale 放大 100 倍，而且要 enterprise-grade：不能漏水、不能停機、tray 還要能抽換維修。

怎麼從工程元件變成投資線索？

  1. 需求不是從散熱開始，是從 AI 算力開始。Hyperscaler 要更多 AI 算力，所以 NVIDIA 推更強 GPU。
  2. 更強 GPU 帶來更高功耗。H100 700W → B300 1400W，單顆 GPU 熱量大幅上升。
  3. 熱排不出去，GPU 就跑不滿。散熱不夠會 thermal throttle，昂貴算力無法 full utilization。
  4. 所以液冷從 optional 變成必要。風扇不夠了，必須用 cold plate、CDU、manifold、UQD。
  5. 必要零件變多，BOM 變大。以前 server 散熱是風扇 + heat sink；現在一整櫃要一套液冷 plumbing，單櫃 cooling BOM 接近 $50K。
  6. BOM 變大，供應商收入機會變大。如果 GB300 rack 出貨增加，每一櫃都要這套液冷，零件廠的訂單量和 ASP 可能上升。
  7. 所以才看公司，但只是 watchlist。cold plate → 奇鋐 / 雙鴻；manifold → 雙鴻；CDU / rack cooling → Vertiv；hybrid fan → 建準。接下來要看法說有沒有證實 NVDA 平台暴露、backlog、毛利。
錯誤投資邏輯：AI 很熱 → 散熱股買。
正確投資邏輯：AI 算力需求上升 → GPU power density 上升 → rack cooling 從 optional 變 required → cooling BOM per rack 上升 → 指定零件供應商 ASP / volume 有機會上升 → 用公司法說驗證 revenue / margin / backlog。
BOM（Bill of Materials）— 跨層概念

是什麼：一台設備的零件成本表。每個零件多少錢、占整台百分比。

BOM不是
零件採購成本公司營收（revenue）
系統內每個零件的權重公司利潤（margin）
「GB300 cooling BOM ~$50K」= NVIDIA 採購整套液冷的成本不等於某家供應商賺 $50K

BOM uplift：新一代產品比上一代貴多少。例：GB200 → GB300 cooling BOM 從 ~$41.5K → ~$49.86K，整體散熱供應鏈水位往上。

為什麼投資人關心：BOM 占比高的零件，零件廠 ASP 容易跟產品升級一起上漲。但賺多少要看「ASP × shipment × market share」，不是直接拿 BOM 數字。

怎麼從成本表變成投資線索？

  1. 先找產品升級。例如 GB200 → GB300，不只是 GPU 更強，整櫃散熱、電源、連接器都變複雜。
  2. 再看哪個零件的 content per unit 變大。如果每櫃散熱 BOM 從 $41.5K → $49.86K，代表每賣一櫃，散熱供應鏈拿到的內容價值變大。
  3. 接著問誰拿到這段 BOM。cold plate / CDU / manifold / UQD 各有不同供應商，不是一家公司吃全部。
  4. 最後回財報驗證。看 ASP、shipment、gross margin、backlog 是否跟 BOM uplift 同步改善。
錯誤投資邏輯：BOM 變大 → 供應商一定賺更多。
正確投資邏輯：BOM 變大 → 找出哪個零件 content 變大 → 找到供應商 → 用 ASP / volume / margin / backlog 驗證。
GB300 整櫃（NVL72）— L5

是什麼：NVIDIA 把 Grace CPU + Blackwell Ultra (B300) GPU + NVLink switch + 散熱 + 電源整合成一個 rack。

GB300 不是「一張 GPU」。NVIDIA 已經 不再賣單片 GPU 給 AI。賣的是 rack-level system。

規格

  • 72 顆 B300 GPU + 36 顆 Grace CPU + 9 個 NVSwitch tray
  • 整櫃功耗 132-140kW、重量 ~1500kg
  • 整櫃售價（業界拆解）約 600,000 美元

跟之前的差別

過去現在 GB300
採購單位：一張 H100採購單位：一個 NVL72 rack
散熱：風扇 + heat sink散熱：cold plate + CDU + manifold + UQD 一整套
主板：標準主板：高階 MLCC 5-10x、ABF 載板

怎麼從整櫃系統變成投資線索？

  1. NVIDIA 從 chip seller 變 rack system seller。買方不只買 GPU，而是買一整套 reference design。
  2. Reference design 指定一整串零件。散熱、電源、HBM、CoWoS、ABF、被動元件都跟著整櫃出貨。
  3. 每一櫃出貨都帶動一包供應鏈。不是單一 GPU 出貨，而是一組 rack-level BOM 出貨。
  4. 所以看 GB300 ramp 時，要看每層供應商。ODM 組裝、散熱零件、HBM、被動元件、電源都會被拉動，但彈性不同。
錯誤投資邏輯：GB300 很貴 → NVIDIA 以外所有供應鏈都大賺。
正確投資邏輯：GB300 整櫃化 → 每櫃固定需要一整套 BOM → 找 content per rack 提升最大的環節 → 看實際 shipment / margin。
HBM（High Bandwidth Memory）— L1 至 L2

是什麼：高頻寬記憶體。3D 堆疊 + TSV（穿矽通孔）放在 GPU 旁邊。

HBM ≠ 一般 DRAM。HBM 比 DDR 貴 5-10 倍。跟 commodity DRAM 是兩條曲線。

解決什麼問題：memory wall — GPU 算力越來越快，但 DRAM 餵料速度跟不上。HBM 把記憶體頻寬拉到 TB/s 等級，讓 GPU 不用等資料。

廠商地位
SK hynixNVIDIA 主要供應，HBM3E 領先
Micron追趕中，受美國政策加分
SamsungHBM3E / HBM4 認證進度落後

節奏：HBM3 → HBM3E (current) → HBM4 (2026-2027)。

怎麼從記憶體變成投資線索？

  1. GPU 算力提升後，資料餵不進去會浪費算力。這就是 memory wall。
  2. HBM 把記憶體貼近 GPU。頻寬提升，GPU 比較不會等資料。
  3. HBM 供給變成 GPU 出貨瓶頸。GPU 有了，如果 HBM 或 CoWoS 不夠，整顆 AI chip 還是出不了貨。
  4. 所以看 HBM 廠，不只看 DRAM 景氣。要看 NVIDIA / AMD 配額、HBM3E / HBM4 認證、ASP、毛利。
錯誤投資邏輯：AI 帶動 HBM → DRAM 全部都漲。
正確投資邏輯：AI 算力需要高頻寬 → HBM 變必要瓶頸 → 看 SK hynix / Micron / Samsung 的 HBM 配額、認證、ASP、margin。
被動元件（Passive Components）— L3

是什麼：電容（capacitor）、電阻（resistor）、電感（inductor）。不是 IC，但每塊主板都需要。

為什麼 AI server 需要更多 / 更高階

  • CPU + GPU 同時拉電，供電瞬間電壓波動大
  • 高階 MLCC（多層陶瓷電容）才能穩定供電
  • AI server 主板高階 MLCC 數量比一般 server 多 5-10 倍

玩家

地區廠商
日本村田、太陽誘電
台灣Yageo（國巨）、華新科、信昌電
韓國Samsung Electro-Mechanics

怎麼從小零件變成投資線索？

  1. AI 主板功耗上升。CPU + GPU 同時拉大電流，供電瞬間波動變大。
  2. 電壓不能亂跳。否則晶片不穩、訊號不穩、系統容易出錯。
  3. 高階 MLCC / 電感需求變大。用量變多，規格變高，content per board 上升。
  4. 投資驗證看高階產品 mix。不是看整個被動元件景氣，而是看 AI server / high-end MLCC 是否拉 ASP、毛利、交期。
錯誤投資邏輯：AI server 要更多零件 → 被動元件全部受惠。
正確投資邏輯：高功耗主板 → 高階 MLCC / 電感用量與規格上升 → 看高階料 ASP / mix / 交期，不看低階 commodity。

客戶所有人就是 hyperscaler 自己
賣方NVIDIA / AMDhyperscaler + 設計合作夥伴
ASIC BOM ≠ GPU BOM：ASIC 是 平行 的供應鏈，不是 GPU 外溢。Google TPU 用 Broadcom 設計 + TSMC 製造 + 自家 HBM 配額；跟 NVIDIA GB300 是 兩條完全不同的 BOM。把 ASIC 寫成「GPU 外溢」是錯誤類比。

怎麼從自研晶片變成投資線索？

  1. Hyperscaler 不想完全依賴 NVIDIA。GPU 好用但貴，毛利大多被 NVIDIA 拿走。
  2. 自家 workload 可以用專用晶片優化。例如 inference 固定、模型架構固定，就能用 ASIC 換更好的 perf/W。
  3. 但 hyperscaler 不一定自己做完。它們定義需求，Broadcom / Marvell / Alchip / GUC 幫忙設計，TSMC 幫忙製造。
  4. ASIC 仍吃共用瓶頸。TSMC 先進製程、CoWoS、HBM 都可能跟 NVIDIA GPU 搶產能。
  5. 投資驗證看設計 win + 量產時點。不是「有 ASIC 需求」就算數，要看 customer、project size、ramp schedule。
錯誤投資邏輯：hyperscaler 做 ASIC → Broadcom / Marvell 全部受惠。
正確投資邏輯：hyperscaler 自研需求 → 設計合作商拿 design win → TSMC / HBM / CoWoS 配額能跟上 → project ramp 進 revenue。

5. 必要背景（4 點心法）

  • rack-scale vs box-scale 思維：AI server 是 rack 級系統。任何「GPU 受惠」分析如果只看單片 GPU，就漏掉 rack 一半的故事。
  • NVIDIA reference design 決定供應鏈分配：hyperscaler 通常照 NVIDIA reference 採購，NVIDIA 一改 spec，整條供應鏈跟著動。
  • 真正的買方是 hyperscaler：Microsoft / Meta / Google / Amazon 的 capex 才是這條 thesis 的真正驅動。
  • TSMC 是 single point of failure：B300、Trainium、TPU、AMD Instinct 全在 TSMC 做。TSMC 產能分配 = 誰能出貨。

8. 最小可記住版本（10 條）

1AI server 不是 GPU 一張，是 rack 一台。
2GB300 一櫃 ~$600K，包含 72 GPU + Grace + 散熱 + 電源。
3BOM = 零件成本表，不是公司營收。
4散熱從旁料變大 BOM，因為 rack 功耗破 130kW。
5散熱拆 4 段：cold plate / CDU / manifold / UQD。

9Forecast 跟 fact 永遠分開；看時態。
10Component supplier（奇鋐）跟 system integrator（Vertiv）不能直接比百分比。
