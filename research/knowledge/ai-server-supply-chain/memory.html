1. 這是什麼？

HBM 是把多顆 DRAM die 垂直堆疊、用 TSV（Through-Silicon Via）連接的高頻寬記憶體。它透過 CoWoS 等先進封裝直接貼到 GPU / ASIC 旁邊，提供比一般 DDR 高一個數量級的頻寬。 DRAM（伺服器主記憶體）與 NAND（SSD）是 AI server 內較傳統、cyclical 的記憶體層。

  • HBM 是 AI server compute 的「記憶體配對件」，與 GPU/ASIC 同封裝。
  • DRAM 是傳統伺服器主記憶體，週期性需求。
  • NAND 是儲存層，受 capex 與 inventory cycle 影響大。
