## Reading Goal

Decide what the `>50% server CPU revenue market share` claim really is, and how

## 這份 Source 在解決什麼問題

兩份 source 解決的是不同問題：

- **Q1 2026 press release**: AMD 現在 Data Center / EPYC / Instinct 動能有沒有
  在財報裡出現？什麼速度？什麼比重？
- **2025 Financial Analyst Day press release**: AMD 管理層希望未來 3-5 年把公司
  帶到什麼位置？server CPU 在這套長期 model 裡是什麼角色？

把它們混用的常見錯誤：把 Analyst Day 的「3-5 年 target」當成 Q1 已實現的事實。

## Reading Lens (這類 Source 一般怎麼讀)

兩份都是公司 press release / IR 級別 primary source。一般要這樣讀：

- 公司 earnings release：先看 reported financials 與 segment results；它的優勢
  是「已發生」，弱項是它常把幾個成長來源綁在同一句（例：EPYC + Instinct 一起
  講），不能單獨歸因。
- IR / Analyst Day press release：是公司給市場的長期戰略意圖。它的優勢是
  framework 與 target，弱項是它本質上是 forward-looking。
- 兩者都會在文末附 Safe Harbor / Cautionary Statement，明確標示哪些屬於
  forward-looking statements。讀的時候要先掃這段，再回頭看本文。

Vocabulary 對應 claim type：

| 字眼 | 意義 |
|------|------|
| `was`, `reported`, `delivered`, `posted` | reported-fact |
| `expects`, `plans`, `intends`, `believes`, `projects`, `aims to` | management-expectation / forward-looking-target |
| `guides`, `outlook`, `range of` | guidance（short-term forward-looking） |
| `targets`, `long-term model`, `next three to five years` | forward-looking-target |
| `analysts say`, `media reports`, `transcript paraphrase` | secondary-interpretation |

Sections to read first：earnings release → segment summary、outlook、cautionary
statement；Analyst Day → "Long-Term Growth Targets" 段落 + cautionary statement。

## What This Source Proves

- AMD Q1 2026 Data Center revenue $5.8B、+57% YoY，已成為公司主要成長引擎。
- 管理層公開把 inferencing / agentic AI 與 server CPU compute 需求綁在一起。
- AMD 在 Analyst Day 把 EPYC server CPU 列為 3-5 年 leadership 戰場，並用
  `revenue market share >50%` 當公開 KPI。
- 短期 (Q2) guidance 強：總 revenue ~$11.2B、server CPU revenue +>70% YoY。

## What This Source Does Not Prove

- AMD server CPU 現在已過半。
- AMD 已單獨贏過 Intel 的 server CPU 業務。
- Agentic AI 已造成可量化的 CPU attach rate 提升。
- `>$120B` 是 AMD 公司 revenue（它是 server CPU TAM）。
- Meta 6GW 計畫已轉成已認列的 AMD revenue。

### Mental Model Update

- AI server 不只 GPU；AMD 在公開文件把 EPYC 從「成熟 CPU 業務」重新框成
  AI infrastructure 長期成長核心。
- AMD Q1 release 與 Analyst Day 是兩種工具：Q1 講「現在進度」，Analyst Day
  講「3-5 年戰略意圖」。引用任一段都要先回答「我在說 progress 還是 intent」。
- AMD 在 segment level 常把 EPYC + Instinct 一起講；只看 Q1 release 沒辦法把
  server CPU 與 GPU 拆開來歸因，需要 transcript / supplemental 才能拆。
- `revenue market share` 可以靠高價 mix 拿下，也可以靠低價搶量拿下；之後追蹤
  時 gross margin 跟市占要一起看，否則會誤判競爭力。
  **Mercury Q4 2025 update**: AMD revenue share (41.3%) 顯著高於 unit share
  (28.8%)，差距 12.5 ppt → 強烈支持「AMD 拿的是高價端 share」這個結論，不是
  低價搶量。配合 AMD non-GAAP gross margin 持續 50%+ 一起看，這條 mental
  model 從假設變成 source-backed conclusion。
- 「target vs current」是另一個 mental model：AMD 公開目標 >50%、當前 41.3%、
  gap ~8.7 ppt、年增 ~5 ppt。在 3-5 年內達標機率高，但 Intel 防守動作 +
  hyperscaler 採購節奏會影響速度，不能假設線性外推。

## Tutor Explanation

把這兩份 source 當成兩種工具，不要混用。Q1 release 回答「現在發生了什麼」；
Analyst Day 回答「AMD 想去哪裡」。

讀的時候對每句話問四件事：

1. 動詞是過去式還是未來式？
2. 是公司 revenue、segment revenue、guidance、TAM，還是 share？母體不同不能混。
3. 時間框架是已實現、下一季、全年，還是 3-5 年？
4. 它直接支撐哪個結論？我有沒有把它推太遠？

AMD 的 `>50% server CPU revenue market share` 不是 isolated claim，它在 Analyst
Day 的 `Long-Term Growth Targets` 段落，前面綁著「next three to five years」。
所以正確讀法是「3-5 年 forward-looking target」，不是現況。

## Checkpoint Questions

- 哪句話是 reported-fact？ → "Data Center segment revenue was $5.8 billion, up
  57% year-over-year..."
- 哪句話只是 management expectation 或 target？ → "AMD expects to achieve more
  than 50% server CPU revenue market share."
- 哪句話拿掉 `expects` 或 `targets` 就會變誤導？ → 同上；以及「server CPU TAM
