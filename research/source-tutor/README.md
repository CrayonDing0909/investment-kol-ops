# Source Tutor Notes

Purpose: store source-by-source reading notes that teach how to interpret primary
and high-value secondary sources before they become brief claims or public
content.

Naming:

```text
<theme>/YYYY-MM-DD_<source-id>_reading.md
```

Use `research/templates/source-tutor-reading.md` for each note. The key invariant
is to classify every important claim as a reported fact, management expectation,
forward-looking target, secondary interpretation, agent inference, or open item.
