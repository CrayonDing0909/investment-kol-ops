# Algorithm Research System

Purpose: learn what content earns distribution and why, without chasing vanity
metrics blindly.

## Research Questions

- Which topics create reach for investment + AI workflow content?
- Which hooks create clicks, saves, replies, and follows?
- Which formats work best: chart post, thread, video, carousel, demo walkthrough,
  checklist, or story/postmortem?
- What distribution behavior matters: comments, replies, quote posts, saves, dwell
  time, profile clicks, link clicks, or shares?
- Which platform rewards which content behavior?

## Platforms to Track

- X / Twitter.
- Threads.
- YouTube Shorts.
- Instagram Reels.
- Newsletter/blog.
- LinkedIn, if the angle becomes professional AI workflow.

## Swipe File Fields

For every good post, record:

- Platform.
- Creator.
- Topic.
- Hook.
- Format.
- Visual style.
- CTA.
- Comment pattern.
- Approximate metrics.
- Why it likely worked.
- How to adapt without copying.

## Metrics to Track

- Impressions.
- Engagement rate.
- Replies/comments.
- Saves/bookmarks.
- Shares/reposts.
- Profile visits.
- Follows.
- Link clicks.
- Demo signups or feedback.
- Qualitative replies.

## Interpretation Rules

- A post with fewer impressions but high saves/comments can be more valuable than a
  viral low-trust post.
- For MVP discovery, comments and DMs are more valuable than likes.
- For trust-building, clarity and source quality matter more than sensational hooks.
- For algorithm learning, compare posts within the same platform and time window.

## Weekly Review

Every week:

1. Pick top 3 posts by reach.
2. Pick top 3 posts by depth signal: saves, replies, DMs, signups.
3. Identify one repeated hook or format.
4. Identify one topic to stop.
5. Decide next week's experiment.
