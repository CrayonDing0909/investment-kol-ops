## Pattern Synthesis

### Pattern 1 — One concrete number or conflict first

Real examples usually do not start with setup. They start with a number, quote,
or tension.

For Card #001:

```text
GB300 一櫃要花接近 $50K 在液冷上。
```

Keep this as the first line. It is stronger than:

```text
最近整理 GB300 散熱這條...
```

### Pattern 2 — Make the post saveable

The strongest X examples provide a structure readers can reuse:

- list of phases
- checklist
- business map
- chart / metric table
- mechanism chain

For Card #001, the saveable object is:

```text
AI 算力需求
→ GPU power density
→ rack cooling
→ cooling BOM
→ supplier ASP / volume
→ revenue / margin / backlog
```

This should stay in the post.

### Pattern 3 — Mechanism before ticker

The useful examples do not start with a ticker list. They first show why the
thing matters, then map it to companies.

For Card #001:

```text
heat / rack power → liquid cooling requirement → BOM increase → company mapping
```

is better than:

```text
奇鋐 / 雙鴻 / Vertiv 受惠
```

### Pattern 4 — Reply-worthy question beats generic CTA

X rewards conversation depth. A CTA should not be “read my link” first.

For Card #001:

```text
如果你也在看 AI server 供應鏈，你會先追散熱、HBM，還是 ASIC 這幾條線？
```

is better than:

```text
完整地圖在這裡
```

The library link can follow after the question or go in the first reply.

### Pattern 5 — Source discipline must stay visible

Investment X can reward bold claims, but this account should not become signal
selling. Caveats should be simple and not derail the post.

For Card #001:

- Do not write `散熱占整櫃 42%`.
- Use `~$50K / rack`.
- Keep disclosure.
- Keep the counter.

## Recommended X Changes

- Raw research voice.

  as a checklist.

```text

cold plate / CDU / manifold / UQD
```

- Test library link placement:
  - main post final lines

### Do Not Copy

- Over-certainty like “next big investment theme.”
- Combative framing if not aligned with account voice.
- Bare quote-dumping without mechanism.
- Chart-only post without source caveats.
