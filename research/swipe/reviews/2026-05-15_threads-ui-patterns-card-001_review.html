Threads UI Pattern Review — Card #001

這頁補的是官方 ranking docs 沒講的東西：Threads 現場長文卡、灰底 preview、點開全文、文字用法。重點不是再背演算法，而是把 Card #001 改成更像 Threads 原生內容。

Status: draft · Phase: UI pattern / long-form attachment · Canonical: markdown canonical

1. 這次新增的 Threads 現場觀察

你的截圖觀察

  • Feed 裡是短外文 + 灰底長文卡 preview。
  • preview 用問題開頭，故意切在 open loop。
  • 點開後是完整長文，不是 10 段留言。
  • 互動 bar 保留在長文閱讀底部。

公開資料觀察

  • Threads 支援 up to 10,000 characters text attachment。
  • 灰底卡可展開 read more。
  • 支援 bold / italic / underline / strikethrough / highlight。
  • 可在 attachment 末端放 source link。

2. Signal → UI Pattern → Card Change

觀察對 Card #001 的改法為什麼
Feed preview 只露出外文 + 長文卡片前幾行Outer post 要短，text attachment 前 3 行要開 loop讀者在 feed 先決定要不要點開
灰底卡讓長文有視覺停頓不要拆成 7-11 段留言，改成一張 long-form attachment更像 Threads native 長文 UI
熱門長文用「你第一個反應是什麼」Attachment 用心理 first reaction 開頭先抓讀者心裡直覺，再翻轉成你的分析
Threads 重視 reply / post click / viewing time保留完整推理，但 outer CTA 問「你先追哪條線？」問題更貼近內容，也更容易回覆

3. Recommended Threads Native Version

Outer post

GB300 一櫃要花接近 $50K 在液冷上。

我原本以為這只是散熱概念股，整理完覺得不是這樣。

你第一個反應可能是： 「散熱不就是風扇嗎？」 「又是 AI server 題材？」 「最重要的不還是 GPU？」 我一開始也差不多。 但整理完 GB300 這條，感覺真正的變化不是「散熱突然很重要」，而是 AI server 已經變成一櫃一櫃的系統在賣。 GB300 NVL72 不是一張 GPU。 它是一台 rack-level system。一櫃裡面有 72 顆名字叫 B300 的 GPU，滿載功耗大概 132-140kW。 140kW 對我來說不是工程數字。 它比較像是在提醒：這一櫃本質上就是一個很貴、很密集的熱源。 熱排不出去，GPU 會 thermal throttle，也就是自己降速保命。 你買了很貴的算力，但跑不滿，就是在浪費錢。大企業當然不會讓這種事發生。 所以液冷開始從 optional 變 required。 拆開看，大概有幾段： - cold plate：貼在晶片上，把熱帶到冷卻液 - CDU：整櫃冷卻液循環的主機 - manifold：把冷卻液分到不同 tray - UQD：快接頭，讓 tray 可以維修又不漏液 公開拆解資料給的量級是： - GB300 NVL72 單櫃液冷 BOM 約 $49,860 - GB200 約 $41,500 BOM 是零件成本表。 這不是某家公司直接賺到的營收，但它說明一件事：每一櫃 AI server 裡，散熱這個 category 的 content 變大了。 也就是說，NVIDIA 每賣出一台 AI server rack，上面就會綁一套液冷系統。 對應到公司，先粗分： - 奇鋐 / AVC：cold plate、液冷模組 - 雙鴻 / Auras：manifold、液冷 solution - Vertiv：rack / data center 層級 cooling infrastructure 但這不是看到名字就買。 我會先把它們放進 watchlist，看後面法說有沒有真的轉成 revenue / margin / backlog。 所以這條線我目前會這樣理解： AI 算力需求上升 → GPU power density 上升 → rack cooling 從 optional 變 required → cooling BOM per rack 上升 → 對應零件供應商 ASP / volume 有機會上升 → 最後回到法說驗證 反向檢查點（算一種利多出盡吧）： 如果未來兩年 AI rack 還是以過渡型液冷為主，沒有更快走向 direct-to-chip / 全液冷，那 cold plate、manifold、CDU 這些零件的成長速度可能就沒有想像中快。 但目前看到的產業資料，方向是 OK 的。 所以我目前不是把它當成「買哪一檔」。 我比較像是把散熱放進 AI server 基本面支線裡追。 如果 rack power 繼續往上，這條線值得繼續看。 如果法說沒有轉成 backlog / margin，那就降級。
