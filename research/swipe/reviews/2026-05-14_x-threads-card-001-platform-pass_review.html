2. 官方資料整理出來的方向

X

  • 重點不是單純 likes，而是 reply、profile click、good click、dwell。
  • 第一行要強，否則沒有 click / profile curiosity。
  • link 不應該太早放，避免打斷 conversation。
  • 結尾要有能回覆的問題，不只是 CTA。
  • 作者應該回早期留言，因為 reply engaged by author 曾是重要 prediction output。

Threads

  • 官方文件強調 feed viewing time、post click、profile tap、reply。
  • Threads 比 X 更像對話，不應直接貼 X 長文。
  • 分段比一大段更適合，讓每段只講一個概念。
  • 問題 CTA 可以偏「你怎麼分類這條線？」而不是「點連結」。
  • source caveat 可以少一點，深入內容放 library。

3. Card #001 — X Version

GB300 一櫃要花接近 $50K 在液冷上。

這是我最近整理 AI server 供應鏈時，覺得最有記憶點的一個數字。

先翻成人話。

GB300 NVL72 不是一張 GPU，而是 NVIDIA 新一代 AI server rack。一櫃裡面有 72 顆 B300 GPU，滿載功耗大概 132-140kW。

140kW 是什麼概念？

你可以先不用管工程細節，只要知道：這一櫃本質上就是一個很貴、很密集的熱源。

熱排不出去，GPU 會 thermal throttle，也就是自己降速保命。你買了很貴的算力，但跑不滿，就是在浪費錢。大企業當然不會讓這種事發生。

所以液冷開始從 optional 變 required。這就是為什麼散熱開始從「風扇」變成「一整套水路」。

拆開看，大概有幾段：

  • cold plate：貼在晶片上，把熱帶到冷卻液
  • CDU：整櫃冷卻液循環的主機
  • manifold：把冷卻液分到不同 tray
  • UQD：快接頭，讓 tray 可以維修又不漏液

對應到公司，先粗分會是：奇鋐 / AVC、雙鴻 / Auras、Vertiv。

如果你也在看 AI server 供應鏈，你會把散熱這條放在「基本面升級」還是「題材輪動」？

完整地圖：https://investment-kol-ops.vercel.app/library/ai-server-supply-chain/
