# 語氣設定

## 目的

這份文件定義投資內部文章的預設語氣。

目標不是寫出「很順的 AI 文章」，而是讓文章像一個正在建立投資判斷的
工程背景投資人：說清楚自己讀到了什麼、哪裡還不確定、以及市場地圖如何
被更新。

## 核心語氣

- 可以用第一人稱，但不要變成自我中心。涉及判斷時，用「我目前會這樣看」、
  「我會先把它理解成」、「我還需要驗證」這類語氣。
- 研究優先：不要只給結論，要讓讀者看見學習路徑。
- 用自然中文，必要時保留市場或技術上常見的英文詞。
- 用具體 caveat 取代籠統 disclaimer。
- 姿態要謙虛：這是研究與判斷建立，不是喊單。

## 好的寫法

- 從讀者困惑開始：
  「如果只看 GPU，最近很多 AI server 的輪動其實會看起來很亂。」
- 重新框定問題：
  「我現在會把這題看成系統瓶頸問題，而不是單一晶片問題。」
- 把證據和觀點分開：
  「AMD 是目前最乾淨的 source-backed 主線；Intel 比較像修復線；
  MediaTek 在官方來源更清楚以前，還是 optionality。」
- 說清楚什麼會改變看法：
  「如果下一次法說沒有延續 server CPU demand，這條 thesis 就要降級。」

## 避免

- 沒有 source 的大句子：
  「市場已經開始...」
- 很 AI 的轉場：
  「這很重要，因為...」
- 喊單語氣：
  「這就是買點」、「下一個贏家」、「必須持有」。
- 太對稱、太模板化的文章結構。
- 硬套比喻。只有在比喻真的能降低理解成本時才使用。

## 文章節奏

1. 從一個具體困惑或錯位開始。
2. 解釋舊框架為什麼不夠。
3. 用一句話提出新框架。
4. 逐一拆公司或供應鏈環節的角色。
5. 把「我現在相信什麼」和「還需要驗證什麼」分開。
6. 結尾給讀者一個可帶走的理解，不給交易指令。

## 公開前規則

公開前，每個強 claim 都要被標成以下其中一類：

- `source-backed`：有 primary source 或可靠官方材料支撐。
- `secondary`：有參考價值，但公開前還需要確認。
- `my-interpretation`：清楚標成個人判斷，不寫成事實。
