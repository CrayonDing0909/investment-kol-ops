# Metrics

Purpose: measure whether the account is learning, growing, and converting attention
into useful products.

## Account Metrics

- Followers.
- Impressions.
- Engagement rate.
- Profile visits.
- Follows per impression.
- Link clicks.
- Newsletter or waitlist signups.

## Content Metrics

- Hook type.
- Topic.
- Format.
- Publish time.
- Impressions.
- Likes.
- Comments/replies.
- Reposts/shares.
- Saves/bookmarks.
- Clicks.
- Follows.
- Qualitative signal.

## MVP Metrics

- Demo visits.
- Completion rate.
- Feedback submissions.
- Repeat usage.
- Waitlist signups.
- User quotes.
- Feature requests.
- Share rate.

## Trust Metrics

- Corrections needed.
- Source issues found.
- Disclosures included.
- Postmortems published.
- Claims revised after review.

## Weekly Review Questions

- Which post created reach?
- Which post created trust?
- Which post created product signal?
- Which audience pain repeated?
- Which format should be repeated next week?
- Which topic should be stopped?
